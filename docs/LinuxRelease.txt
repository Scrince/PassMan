PassMan v1.0.2 - Linux Release Notes
====================================

Release status
--------------

This file records the v1.0.2 Linux packages, their signatures and checksums,
and architecture-specific build notes.

The release includes native x86-64 and ARM64 packages. Each architecture is
available as a standalone PyInstaller tarball and a Debian package. Builds were
produced in Docker with Python 3.14.9, PyInstaller 6.21.0, and PyQt6/Qt6 6.11.0.

The Linux vault location remains:

  $XDG_DATA_HOME/PassMan/vault.dat

or, when XDG_DATA_HOME is unset:

  ~/.local/share/PassMan/vault.dat

Automatic backups are stored as `vault.dat.bak` beside the vault.


Release Artifacts
-----------------

x86-64 / Debian amd64:

  release/v1.0.2/linux/PassMan-linux-x64.tar.gz
  release/v1.0.2/linux/PassMan-linux-x64.deb

ARM64 / Debian arm64:

  release/v1.0.2/linux/PassMan-linux-arm64.tar.gz
  release/v1.0.2/linux/PassMan-linux-arm64.deb

Each package has a detached ASCII-armored OpenPGP signature. The release
includes an OS-specific signed checksum manifest and the signed aggregate
manifest:

  release/v1.0.2/linux/SHA256SUMS
  release/v1.0.2/linux/SHA256SUMS.asc
  docs/SHA256SUMS
  docs/SHA256SUMS.asc

No RPM or AppImage is included.


Verified Package Metadata
-------------------------

Both Debian packages use package name `passman`, version `1.0.2`, section
`utils`, and priority `optional`. The x64 package declares architecture `amd64`;
the ARM package declares `arm64`.

The tarball executables were inspected as ELF 64-bit binaries:

  x64:   x86-64, interpreter /lib64/ld-linux-x86-64.so.2
  arm64: AArch64, interpreter /lib/ld-linux-aarch64.so.1

The tarballs contain the PyInstaller application directory. Do not place or
publish `vault.dat` or `vault.dat.bak` with application packages.

Import the public key and verify a package and both manifests:

  gpg --import docs/PassMan_Release_Signing_2026_pubkey.asc
  gpg --verify release/v1.0.2/linux/PassMan-linux-x64.tar.gz.asc \
               release/v1.0.2/linux/PassMan-linux-x64.tar.gz
  gpg --verify release/v1.0.2/linux/SHA256SUMS.asc \
               release/v1.0.2/linux/SHA256SUMS
  gpg --verify docs/SHA256SUMS.asc docs/SHA256SUMS

The Debian packages are not signed by APT repository metadata. Verify the
OpenPGP signatures and SHA-256 manifest before installing.


Installation
------------

Install a Debian package:

  sudo apt install ./release/v1.0.2/linux/PassMan-linux-x64.deb
  passman

For ARM64, use `PassMan-linux-arm64.deb` instead. The standalone tarballs can
be unpacked and launched directly:

  tar -xzf release/v1.0.2/linux/PassMan-linux-x64.tar.gz
  ./PassMan/PassMan

The GUI requires the Linux desktop libraries documented in `docs/Build.txt`.
