PassMan v1.0.6 - macOS Release
==============================

Build details
-------------

Built on macOS 15.7.7 with Python 3.14.0, PyInstaller 6.22.3, and PyQt6 / Qt
6.11.0. The release provides native Apple Silicon and Intel disk images plus
a universal2 image. The universal app combines the arm64 and x86_64 native
bundles and contains both architecture slices in every Mach-O file.

The x86_64 cryptography 50.0.2 extension was built from source and linked
statically against OpenSSL 3.6.3. It has no runtime OpenSSL library dependency.
The arm64 build uses the cryptography 50.0.2 macOS wheel. The DMGs contain
ad-hoc code-signed apps; they are not Developer ID signed or notarized, so
Gatekeeper may show a warning when opening a downloaded app.
