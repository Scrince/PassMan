PassMan v1.0.2 - Ubuntu 24.04 LTS Release
==========================================

Target and build environment
----------------------------

These packages are built in Ubuntu 24.04 LTS (Noble) Docker containers for
both x86-64/amd64 and ARM64/arm64. The ARM64 container ran natively on the
Apple Silicon build host; the amd64 container used Docker emulation.

Build tool versions:

  Ubuntu 24.04 LTS
  Python 3.12.3
  glibc 2.39
  PyInstaller 6.21.0
  PyQt6 / Qt6 6.11.0

The application is packaged with PyInstaller as an onedir bundle. The Ubuntu
`.deb` files use the Debian package format and declare their architecture as
`amd64` or `arm64`. They are standalone packages, not packages from an APT
repository. The ARM64 PyQt6 6.11 wheel targets glibc 2.39; Ubuntu 24.04 provides that
version. This release is built and intended for Ubuntu 24.04 LTS. Older Ubuntu
releases are not claimed as supported by this build.

-----------------

x86-64 / Debian amd64:

  release/v1.0.2/linux/ubuntu-24.04/PassMan-Ubuntu-24.04-x64.tar.gz
  release/v1.0.2/linux/ubuntu-24.04/PassMan-Ubuntu-24.04-x64.deb

ARM64 / Debian arm64:

  release/v1.0.2/linux/ubuntu-24.04/PassMan-Ubuntu-24.04-arm64.tar.gz
  release/v1.0.2/linux/ubuntu-24.04/PassMan-Ubuntu-24.04-arm64.deb

Each archive and Debian package has an adjacent detached ASCII-armored OpenPGP
signature. The per-release checksum manifest is also signed:

  release/v1.0.2/linux/ubuntu-24.04/SHA256SUMS
  release/v1.0.2/linux/ubuntu-24.04/SHA256SUMS.asc

The aggregate manifest in `docs/SHA256SUMS` includes these four packages and
has a detached signature at `docs/SHA256SUMS.asc`. SHA256SUMS lists the package
files, not their detached `.asc` signature files.

Installation
------------

Install the package matching the system architecture:

  sudo apt install ./release/v1.0.2/linux/ubuntu-24.04/PassMan-Ubuntu-24.04-x64.deb
  passman

Use the `arm64.deb` package on Ubuntu ARM64. The tar.gz packages can be
unpacked and launched directly:

  tar -xzf release/v1.0.2/linux/ubuntu-24.04/PassMan-Ubuntu-24.04-x64.tar.gz
  ./PassMan/PassMan

The desktop GUI requires Ubuntu desktop libraries. Do not include `vault.dat`
or `vault.dat.bak` with application packages.
