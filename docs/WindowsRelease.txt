PassMan Windows Release Verification
====================================

Current release status
----------------------

The v1.0.7 Windows x64 executable, installer, and CycloneDX SBOM were built on
Windows 11 x64 with Python 3.14.5, PyInstaller 6.22.3, and Inno Setup 6.7.3.
The macOS and Ubuntu 24.04 Linux v1.0.7 packages are also ready.

Artifacts:

  release/v1.0.7/windows/PassMan.exe
  release/v1.0.7/windows/PassMan-Setup-1.0.7.exe
  release/v1.0.7/windows/SBOM.cdx.json
  release/v1.0.7/windows/SHA256SUMS

All artifacts and the Windows checksum manifest have detached OpenPGP
signatures. The three artifact hashes are included in the signed aggregate
manifest at docs/SHA256SUMS.

Build command (run on Windows 11 with the pinned requirements and Inno Setup
6 or newer):

  py -m pip install -r requirements.txt
  py build.py --platform windows

The build writes `release/v1.0.7/windows/PassMan.exe` and
`PassMan-Setup-1.0.7.exe`. It passes the versioned executable path directly
to Inno Setup so the installer packages the new executable.

Generate the SBOM from the same Python environment used for the build:

  $pyver = py -c "import sys; print('.'.join(map(str, sys.version_info[:3])))"
  py scripts/generate_release_sbom.py --target "Windows 11" --architecture "x64" --build-environment "Windows 11, Python $pyver" --output release/v1.0.7/windows/SBOM.cdx.json

The release was signed with the repo-local release key. `docs/Build.txt`
contains the full signing procedure and verification commands.

Previous Windows release
------------------------

Installer: release/v1.0.5/windows/PassMan-Setup-1.0.5.exe
SBOM: release/v1.0.5/windows/SBOM.cdx.json (CycloneDX 1.6)
Signed with the PassMan Release Signing (2026) OpenPGP key.

This release authenticates vault header metadata with AES-GCM, migrates v1
vaults after a successful unlock, writes backups atomically, and lets users
move the active vault and backup from Settings. It includes regression tests,
cross-platform CI, and accessibility labels for settings controls. Dependencies
remain cryptography 50.0.2 and PyInstaller 6.22.3. Linux and macOS v1.0.5
packages were not part of the v1.0.5 Windows release; the current macOS and
Linux release notes are maintained separately for v1.0.7.

Verify the signatures and checksums from the repository root:

  gpg --import docs/PassMan_Release_Signing_2026_pubkey.asc
  gpg --verify release/v1.0.5/windows/PassMan.exe.asc release/v1.0.5/windows/PassMan.exe
  gpg --verify release/v1.0.5/windows/PassMan-Setup-1.0.5.exe.asc release/v1.0.5/windows/PassMan-Setup-1.0.5.exe
  gpg --verify release/v1.0.5/windows/SBOM.cdx.json.asc release/v1.0.5/windows/SBOM.cdx.json
  gpg --verify release/v1.0.5/windows/SHA256SUMS.asc release/v1.0.5/windows/SHA256SUMS
  gpg --verify docs/SHA256SUMS.asc docs/SHA256SUMS
  Get-FileHash -Algorithm SHA256 release/v1.0.5/windows/PassMan.exe
  Get-FileHash -Algorithm SHA256 release/v1.0.5/windows/PassMan-Setup-1.0.5.exe

The v1.0.2/windows directory in this working copy contains local vault data
