PassMan v1.0.7 - macOS Release
==============================

Build details
-------------

Built on macOS 15.7.7 with Python 3.14.0, PyInstaller 6.22.3, and PyQt6 / Qt
6.11.0. The release provides native Apple Silicon and Intel disk images plus
a universal2 image. The universal app combines the arm64 and x86_64 native
bundles; all 80 Mach-O files contain both architecture slices.

The x86_64 cryptography extension was built from source and linked statically
against OpenSSL 3.6.3. The DMGs contain ad-hoc code-signed apps; they are not
Developer ID signed or notarized, so Gatekeeper may show a warning when
opening a downloaded app.

OpenPGP verification
--------------------

Primary fingerprint: 7858 E51C 98AD 2541 5098 9EF3 1F4D F0EB 1C80 C710

From the repository root, import the public key and verify the aggregate
manifest:

  gpg --import docs/PassMan_Release_Signing_2026_pubkey.asc
  gpg --verify docs/SHA256SUMS.asc docs/SHA256SUMS
  shasum -a 256 -c docs/SHA256SUMS

From this directory, verify the platform manifest, packages, and SBOM:

  gpg --verify SHA256SUMS.asc SHA256SUMS
  gpg --verify PassMan-macOS-arm64.dmg.asc PassMan-macOS-arm64.dmg
  gpg --verify PassMan-macOS-x64.dmg.asc PassMan-macOS-x64.dmg
  gpg --verify PassMan-macOS-universal.dmg.asc PassMan-macOS-universal.dmg

under `release/v1.0.7/windows/`. The Linux packages are documented in
