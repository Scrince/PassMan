PassMan v1.0.2 - macOS Release Notes
====================================

Release status
--------------

This file records the v1.0.2 macOS artifacts, OpenPGP signatures, checksums,
and packaging notes.

The release builds are packaged as .app bundles inside compressed DMGs. The
application vault format is unchanged. Frozen builds store the vault at:

  ~/Library/Application Support/PassMan/vault.dat

with automatic backup:

  vault.dat.bak

Code Signing vs Release Signing
-------------------------------

  - OpenPGP signatures prove the package bytes match what the release key
    holder published. Verify them before install.
  - The app inside each DMG is ad-hoc codesigned and passes codesign
    verification. The DMGs are not Developer ID signed or notarized. Gatekeeper
    may warn on first open.
  - Apple code signing and OpenPGP release signing serve different purposes.


Operational Notes
-----------------

  - Do not publish vault.dat with application binaries.
  - Prefer the arm64 DMG on Apple Silicon and the x64 DMG on Intel Macs.
  - Verify hashes and OpenPGP signatures before unlocking a real vault.
