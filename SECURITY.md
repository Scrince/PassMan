# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release. Older releases may
not receive security updates; use the latest version listed on the
[Releases page](https://github.com/Scrince/PassMan/releases).

## Reporting a Vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/Scrince/PassMan/security/advisories/new).
Do not report security vulnerabilities in public issues, discussions, or
reviews. Include the affected version, steps to reproduce, and the potential
impact. Please allow the maintainers reasonable time to investigate and
prepare a fix before public disclosure.

If private vulnerability reporting is unavailable, contact the maintainer
through the GitHub profile to arrange a confidential reporting channel. Do not
post vulnerability details publicly.
