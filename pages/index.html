PPassMan
Your vault stays yours

Password management, kept local.

PassMan is an offline-first desktop password manager. Your vault is encrypted on your device and protected by your master password.

Download the latest release View source on GitHub

Available for Windows, macOS, and Linux. Check release notes and verify signatures before installing.

Encrypted local vault

AES-256-GCM encryption and Argon2id key derivation protect vault data stored on your computer.

More than passwords

Keep authenticator entries, recovery information, seed phrases, and project keys in one desktop app.

Open source releases

Review the source, read the security notes, and download signed builds from the project’s GitHub releases.

Designed to stay offline-first

This website only provides project information and links to downloads. PassMan is a native desktop application; the website does not access or store your passwords or vault.
