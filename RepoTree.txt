Production notes
================

- `src/` is the source of truth for application code, version metadata, and packaged
  runtime assets. The top-level `assets/` branding kit is not part of the application.
- `build.py` invokes PyInstaller using `src/main.py`, `src/assets/`, and the project
  version. It creates platform-specific packages on the target operating system;
  Windows installer creation additionally uses Inno Setup and `installer/PassMan.iss`.
  `PassMan.spec` defines the portable PyInstaller bundle path. Build intermediates in
  `build/` and `dist/` are not production source or retained release contents.
- `release/v*/<platform>/` contains retained, signed packages and associated manifests
  and SBOMs. Published release assets may also be distributed through GitHub Releases.
- Linux produces x64 packages in the retained release history; macOS artifacts cover
  arm64, x64, or universal builds; Windows artifacts are x64. Packaging is native to
  the target OS; Windows cross-building from Linux/macOS is unsupported.
- Source execution uses Python 3.12+ with dependencies from `pyproject.toml` (also
  listed in `requirements.txt`). Frozen builds carry their runtime dependencies.
- Vault data is user data created at runtime and is intentionally absent from this
  production source tree description.
